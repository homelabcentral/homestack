The goal of this project is to get the docker compose and .env.template from the api (projects.json) file for a project, parse it, do some compute/processing if needed and then create a .env file and docker-compose file and  write it to disk. 

for now, we just want to create models for .env.template parsing.

The .env.template file is modele like this:

anything in the # METADATA block is metadata for that file
there will be many key - value variables, empty files, inline comments with the key = value variables, and in the inline comments the following keys
recommended - this has a recommended value of the key variable for the .env file, it can be empty or this key can be missing
type - this represents the type of the key, it can be string which is a string of unlimited length, string(min, max) which is a string of the length between minimum and maximum, both min and max are optional, similarly int(min, max) or int, float(min, max) or float, password(min, max) or password, passphrase(min, max) or passphrase, bcrypthash, memory which is formatted 12K, 4M, 6G, 6T for kilobytes, megabytes, gigabytes, and terabytes respectively, it should be in number followed by K,M,G or T format, ip for ip address and port for port. These will be used to validate the inputs in pydantic or questionary
prompt - this represents a string which is the message arg in questionary library
instruction - this represents a string which is the instruction arg in questionary library
choices = [choice1 (description=, default=true|false), choice2] which is the choices arg in questionary library, where description is a string that goes along with the Choice object in questionary and default which is a boolean flag represents if the value is default. both description and default are optional for a choice
description - this represents a string which is the description arg in questionary library

recommended =
type = string|password|bcrypthash|memory|string(length)|passphrase(length)|float(min, max)|int(min,max)|ip (This will be used to validate the input)|port
prompt =
instruction =
choices = [choice1, choice2]
immutable = true|false
description =
